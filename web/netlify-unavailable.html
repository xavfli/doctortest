Bu sayt Netlify’da ishlamaydi

Oilaviy shifokorlik testi — bu Python server ilovasi, statik sayt emas. Shuning uchun Netlify uni ishga tushira olmaydi.

Sabab qanday?

  • Netlify faqat HTML/CSS/JS beradi — backend (server) umuman yo’q.
  • Test baholasi serverda qo’yiladi, to’g’ri javob brauzerga umuman yuborilmaydi.
  • Natija va urinishlar bazada saqlanadi (SQLite).

Shuning uchun /api/... so’rovlari ishlamaydi va Page not found xatosi chiqadi.

To’g’ri joylashtirish

Repozitoriyda Dockerfile va render.yaml tayyor.

  • Render: Dashboard → New → Web Service → repozitoriyni ulash → Runtime: Docker.
  • Railway: New Project → Deploy from repozitoriya (Docker avtomatik aniqlanadi).
  • Server: docker compose up -d — nginx deploy/nginx.conf orqali.

Eslatma: Render bepul rejasida

Disk vaqtinchadir — /app/data/app.db har bir qayta joylashtirishda to’g’riladi. Haqiqiy natijalarni saqlash uchun doimiy disk ulang yoki DB_URL ni Postgres’ga o’zgartiring.
